🍎 即将登陆 Mac App Store

让哪些应用联网，由自己决定。

Netoff 可以按应用切断 Mac 的网络访问；也可以反过来，让每个应用、每个域名在联网前都先获得批准。

了解工作方式获取支持
模式

三种方式，掌控全局

可以先宽松，只关掉不信任的；也可以先严格，只放行批准的。随时可在菜单栏切换模式。

黑名单

一切照常运行，只关掉不信任的应用和地址。

应用白名单

每个应用联网前都要先问一声。可以允许一次、一小时或永久，也可以拒绝。

域名 / IP 白名单

更进一步：每个陌生的域名或 IP 被访问前都需要批准。对信任的应用，一键放行它的全部连接。

菜单栏

随时一键可达。

菜单栏面板列出当前打开的应用，实时显示下载和上传速度，每个应用一个开关。一秒钟就能断开某个应用的网络。

  • 整台 Mac 和每个应用的实时网速
  • 被禁止的应用以红色置顶显示，误关的开关不会被遗忘
  • 不用打开主窗口，就能切换模式
隐私报告与日志

看清谁在和谁通信。

隐私报告按联系的域名数量给应用排名，也按联系它的应用数量给域名排名。点开任一应用，可查看它过去 7 天联系过的每个地址。

  • “网络活动”显示当前打开的连接，以及最近 5 分钟内的连接
  • 完整的连接日志可保留 7、14 或 30 天，也可限制在 5、10 或 200 MB 以内
  • 大小上限是硬上限：Netoff 会删除最旧的记录，日志永远不会超过它
  • 可搜索、导出为 CSV，也可随时清除

隐私优先

数据不会离开这台 Mac。

没有账号，没有统计分析，没有广告，没有服务器。Netoff 不含任何向外发送数据的代码，只观察其他应用的联网行为。规则、日志和报告只保存在这台 Mac 上。

开始使用

一分钟即可上手

开启保护

打开 Netoff 并开启保护，它会安装一个小型网络扩展。

允许网络扩展

macOS 会请求一次批准：系统设置 › 通用 › 登录项与扩展 › 网络扩展。

选择模式

选择黑名单或其中一种白名单即可，其余设置均为可选。

Netoff 使用 Apple 的网络扩展（Network Extension）框架，这是由 macOS 自身运行并监管的内容过滤器。它只关注哪个应用在连接哪里，不会读取网页、消息或文件的内容。需要 macOS 15 或更高版本。

常见问题

先了解一下

Netoff 能看到密码或消息吗？

不能。Netoff 只能看到哪个应用向哪个域名或 IP 地址、哪个端口发起了连接，不会读取流量内容。唯一会查看内容的是未加密的 DNS 应答，仅在内存中处理，用来在 IP 地址旁标注域名。

Netoff 没有运行时会怎样？

过滤器运行在系统扩展中，所以即使关闭 Netoff 窗口，规则依然生效。需要批准的连接会按设置中的选择被允许或阻止，直到 Netoff 重新打开。

它是防火墙或杀毒软件吗？

不是。Netoff 按应用控制出站连接，不是入站防火墙，也不扫描恶意软件。

数据保存在哪里？

只保存在这台 Mac 上。规则、隐私报告和连接日志不会离开它。详情及如何删除全部数据，请见隐私政策。

如何卸载？

在 Netoff 的设置中选择“卸载扩展…”，然后把应用移到废纸篓。详细步骤见技术支持页。
